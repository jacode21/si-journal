Runway Released Its Robot Model’s Weights for Anyone to Download, Under a Licence That Allows Commercial Use

Runway made Praxis-1, its 27-billion-parameter robot model, downloadable on Wednesday, November 11, with its weights and training code under the Apache 2.0 licence, which allows commercial use. The model predicts a short video of what should happen next and derives a robot’s actions from it. Runway reports a 46.2% success rate across 1,200 simulated test episodes on NVIDIA’s RoboLab-120 benchmark. Those figures are Runway’s own and have not been independently reproduced.
Edited by Avery Lane · Frontier Editor  ·  Issue No. 025  ·  Thursday, November 12, 2026

Praxis-1 began as a video model. Runway, best known for the video tools filmmakers use, trained it on large amounts of video, then taught it robot control: the system imagines a short clip of what should happen next and works out the movements that would produce it. Each call produces about 1.6 seconds of motion. The release includes three versions of the model, inference code and fine-tuning code, on GitHub and Hugging Face, and it runs on hardware from a data-centre graphics card to the computer inside the robot.

Runway’s headline figure needs its context stated plainly. On RoboLab-120, a simulated benchmark of 120 tabletop tasks run 10 times each, the fine-tuned model completed 555 of 1,200 episodes, a 46.2% success rate, ahead of the 42.9% Runway cites for a rival system. First place on that table still means failing more often than succeeding, on simulated tabletop tasks rather than a factory floor. No independent lab has reproduced the result yet.

The release matters for a different reason. This paper’s standing test, set in Edition 017, is that a model is open when its weights can be downloaded. Praxis-1 passes it completely, with a licence that allows a business to build on it. Three launch partners — Noble Machines, Standard Bots and Ultra — have run it on real machines, Runway says. What an open robot model gets used for, and where it fails in the real world, is now a public record anyone can add to.
